# Rock, Paper, Scissors  
Game Language - English

Players: User vs Computer

Game sequence:

1. A message `input` is displayed with an option to enter an answer - to play the game: rock, scissors, paper.  
Enter one of the valid `str` inputs - `rock`, `paper`, `scissors`.  
2. After input and pressing Enter, ASCII art is displayed - "user" with the corresponding user-selected input, in ASCII art style - rock, scissors, or paper.  
ASCII art of a robot face with the corresponding ASCII art element is displayed.  
3. The game result is displayed - win, loss, or draw (`win`, `loss`, or `draw`).  
4. The game repeats 4 more times (5 times total), and at the end, ASCII art is displayed - Victory, Loss, or Draw result, respectively.  
5. At the end of the game, statistics are displayed with the number of wins, losses, and draws.  
6. If there are invalid inputs, the number of invalid inputs is displayed at the end.
